# Automated Material Tool for Unreal Engine

A Python-based workflow tool developed to automate repetitive material setup tasks in Unreal Engine.

The tool was created during an animated film production to reduce manual texture setup and improve consistency across environment assets.

## Features

- Automatic detection of Base Color, Normal, ORM, and Emissive textures
- Automatic texture grouping
- Regular texture and UDIM / Virtual Texture support
- Automatic Material Instance creation and updating
- Automatic texture parameter assignment
- Static Mesh matching
- Material assignment to matching assets
- Texture naming cleanup
- Substance Painter export preset workflow

## Tech Stack

- Unreal Engine 5
- Python
- Unreal Python API
- Substance 3D Painter
- Material Instances
- UDIM / Virtual Texturing

## Production Use

This tool was used during a team-based animated film production for several months to automate repetitive material setup across multiple assets.
